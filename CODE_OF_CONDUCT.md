# Code of Conduct for this Repository

As a member of our community, we ask that you follow these rules to ensure a safe and respectful environment for everyone.

## Be Kind and Respectful

We want everyone to feel welcome and valued. Please be kind and respectful to each other in all interactions.

## Human written code

All pull requests must be reviewed and submitted by humans, not by AI's. This helps to ensure that code is of the highest quality and meets our standards.
